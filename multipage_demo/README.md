# Multipage Demo

Local coursework app for DVN36104 Session 2. Python 3.11.

Run: `pip install -r requirements.txt`, then `streamlit run app.py` from this folder.

Prepared for Streamlit Community Cloud deployment. The course requires a public GitHub repository and a Streamlit Community Cloud URL. No app URL has been invented, and no Canvas submission has been made.
